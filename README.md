# Atlas Finance — Credit Portfolio & Delinquency Analysis

[Português](README.md) | [English](README.en.md)

Data Analytics portfolio project focused on a fictional consumer credit portfolio.

The goal of the project is to understand **where credit risk is concentrated in the portfolio**, using SQL Server and Power BI.

## Central Question

**Which characteristics are most associated with delinquency, and where should the company focus its attention?**

## Stack

- SQL Server / T-SQL
- Power BI
